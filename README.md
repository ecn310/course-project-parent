# Intergenerational Mobility and Parental Time Investment: A State-Level Analysis
This repository contains the final report and reproducability package containing the data, code, and outputs for ECN 310 Parent group.
## Abstract 

This study examines the relationship between parental time investments and intergenerational mobility in the United States. Using data from the American Time Use Survey and Opportunity Insights, we explore how intergenerational mobility relates to parental time investments in a cross-section of U.S. states. We find that there is a strong relationship between our two studied variables for higher income individuals, and a somewhat strong relationship for lower income individuals. These results show that parental time investment may help explain how state-level mobility shapes economic outcomes across generations.
